# Telegram Channel Relay

نظام خفيف لإعادة نشر المحتوى الجديد من عدة قنوات Telegram إلى قناة هدف، باستخدام جلسة حساب Telegram حقيقية وبوت تحكم. يعمل النظام على خادم دائم، ويركز على النشر اللحظي دون تخزين محتوى المنشورات.

## الحالة الحالية

المشروع في مرحلة **التصميم المعتمد قبل التنفيذ**. النظام القديم محفوظ في فرع:

```text
legacy/smart-poster
```

والفرع `main` مخصص لإعادة بناء النظام الجديد من الصفر.

## القرارات المعتمدة

- مراقبة قنوات عامة أو خاصة يكون الحساب عضوًا فيها.
- نشر الرسائل الجديدة فقط.
- عند بدء التشغيل أو عودة الاتصال: اعتماد أحدث رسالة حالية كنقطة بداية، وتجاهل ما فات أثناء التوقف.
- نسخ الرسالة كرسالة جديدة، وليس Forward.
- دعم النصوص والوسائط والألبومات.
- إزالة الروابط وحقوق المصادر الظاهرة واستبدالها بتوقيع ورابط ثابتين خاصين بنا.
- إزالة الرموز التعبيرية من النص المنسوخ.
- التحكم الكامل من خلال بوت Telegram.
- استخدام SQLite بسيطة لتخزين الإعدادات والمصادر وآخر مؤشر قراءة فقط، دون تخزين محتوى المنشورات.
- حفظ جلسة الحساب بشكل آمن خارج Git.

## الفروع

- `main`: النظام الجديد.
- `legacy/smart-poster`: النسخة القديمة كاملة للرجوع إليها عند الحاجة.
